# План подготовки и показа проекта

Основан на [RUN.md](RUN.md). Демо-логины (пароль у всех `Demo#2026ab`): `demo.admin`, `demo.nazarov` (преподаватель), `demo.azizov` (студент).

## За день до защиты

- [ ] Проверить, что PostgreSQL 18 запущен (порт 5432).
- [ ] Секреты .NET заданы в `src\StudentsTracker.Web` (шаг 3 в RUN.md).
- [ ] Чистая проверка: пересоздать базу (RUN.md, раздел 6) и загрузить `db\schema.sql`, затем `db\seed.sql`.
- [ ] `cd src` и `dotnet test`: ожидается 41 из 41.
- [ ] Сделать дамп `pg_dump` как запасной вариант (RUN.md, раздел 6). В git дамп не добавлять.
- [ ] Заполнить титульный лист, обновить содержание в Word (F9), распечатать.
- [ ] Загрузить `seed.sql` в день показа или за день до него: даты занятий считаются от текущей даты.

## Перед показом

- [ ] Запустить `dotnet run --urls http://localhost:5290`.
- [ ] Открыть http://localhost:5290/api/health, ожидается `{"status":"ok"}`.
- [ ] Открыть три окна или профиля браузера под разными ролями.

## Сценарий показа (около 7 минут)

1. **Администратор** (`demo.admin`): группы и студенты, поиск по ФИО, попытка удалить группу со студентами (ответ 409 с причиной), создание учётной записи студента.
2. **Преподаватель** (`demo.nazarov`): «Мои занятия», создание занятия сразу для нескольких групп, экран отметки: по умолчанию «Был», отметить отсутствующих, «Все были», «Как в прошлом часе», сохранить. Три последних занятия без отметки подходят для показа.
3. **Отчёты**: группа за период, фильтр по дисциплине, переход в отчёт по студенту, прочерк при пустом знаменателе.
4. **Администратор**: исправить отметку на «Уважительная» по справке, показать пересчёт процента.
5. **Студент** (`demo.azizov`): личный кабинет, ширина 360 px (режим телефона в браузере), тёмная тема.
6. **Права**: студент и преподаватель не видят чужих данных (прямой адрес чужого отчёта даёт 403).

## Если что-то сломалось

| Проблема | Действие |
|---|---|
| Нет подключения к базе | Проверить пароль в секретах, служба PostgreSQL запущена |
| Данные испорчены | Восстановить из дампа (RUN.md, раздел 6) или пересоздать базой `schema.sql` и `seed.sql` |
| Порт занят | Запустить с `--urls http://localhost:5291` |
| Нет интернета | Не страшно: шрифты и иконки локальные |
