# План работ: веб-приложение учёта посещаемости студентов

Сроки сдачи: 13–14.11.2026 — черновик печатного документа (введение, главы 1 и 2); 17–18.11.2026 — весь проект (работающее приложение и полный документ). План пересчитан 08.11.2026. Прежний личный дедлайн 09.11 отменён.

Специальность: «Искусственный интеллект», группа 2_40.03.01ра, ХПИ ТТУ.

## 1. Зафиксированные решения

| Область | Решение |
|---|---|
| Backend | C#, ASP.NET Core 10 (.NET 10 LTS); стиль API выбирается при создании каркаса и не смешивается |
| ORM | EF Core 10 + Npgsql (провайдер для EF Core 10), миграции |
| БД | PostgreSQL 18 (установлен у владельца, защита на его компьютере) |
| Frontend | Статичные HTML/CSS/JS в `wwwroot`, без фреймворков, `fetch` к REST API того же origin |
| Авторизация | Cookie-аутентификация, хеш пароля через `PasswordHasher`, роли `admin` / `teacher` / `student` |
| Учётные записи | Создаёт админ: логин + временный пароль. Свободной регистрации нет |
| Назначение | Универсальная система для любого учебного заведения и любого расписания; не интегрируется с системами конкретного вуза |
| Дизайн | Единый источник: `mockups/!DESIGN_TOKENS.html`. Две темы, desktop-first; кабинет студента проверяется на 360, 768, 1280 px. Принятые макеты: `01-login.html`, `02-prototype.html` |
| Шрифты | Локально в `wwwroot/fonts`, без CDN |
| Документ | `docs/PROJECT_DOC.docx`, оформление по ГОСТ 7.32-2017 до подтверждения преподавателя |

Чего не делаем: микросервисы, CQRS, репозитории поверх EF, SPA-фреймворки, JWT, Docker, оценки, интеграция с внешними системами, модуль ИИ.
