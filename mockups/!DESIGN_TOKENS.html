Design Tokens — учёт посещаемости студентов

Единый источник дизайна для всех макетов и итогового интерфейса. Значения берутся отсюда и больше нигде не придумываются заново. Страница растёт вместе с принятыми экранами: новые токены и иконки добавляются по мере утверждения.

1Принятые решения

Журнал утверждённых параметров. Каждое решение фиксируется здесь до того, как попадает в макеты.

05.11.2026ОсноваВариант D3: графит, шрифт Manrope, радиусы 14 и 20 px.

Отметка статуса — сегментный переключатель из четырёх кнопок; на телефоне только иконки.

2Цвета

Имена переменных одинаковы в обеих темах, меняются только значения. Значения на странице читаются из CSS, поэтому всегда совпадают с реальными.

3Контраст

Рассчитывается на странице по формуле WCAG. Порог для обычного текста — 4,5. Значения ниже порога отмечаются красным.

Тени

В светлой теме — лёгкая тень карточек 0 1px 3px rgba(20,20,20,.07). В тёмной тени нет: слои разделяются цветом и границей. Переменная --shadow.

6Базовые компоненты

Эталонный вид кнопок, карточки, бейджей статусов и таблицы отметок в обеих темах. Новые компоненты добавляются после утверждения экранов.

7Иконки SVG

Правила: viewBox 24x24, линия 2 px, скруглённые концы и углы, без заливки, цвет через currentColor. Использование: <svg><use href="#i-save"/></svg>. Набор пополняется по мере появления экранов.
